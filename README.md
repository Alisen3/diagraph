# DiaGraph

Project web page for DiaGraph, a medical knowledge graph for patients and clinicians. CS491 Senior Design Project, Bilkent University.

Built with Next.js. No backend.

```bash
npm install
npm run dev   # http://localhost:3000
```

Deployed on Vercel from the `main` branch.
